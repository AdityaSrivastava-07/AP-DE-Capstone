# ⚔️ Heroics: Campus Event & Club Management Platform
*“Where campus legends are made.”*

Heroics is a full-stack, gamified campus management ecosystem. It transforms standard college events into **Quests**, student organizations into **Guilds**, and students into **Heroes**. By participating in campus life, students earn XP and badges, driving engagement through gamification.

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL with Prisma ORM
- **Authentication:** JWT (JSON Web Tokens)
